## 🚀 Projects Overview

### 1. Text-Based Hangman Game
A classic word-guessing game built completely in the command-line interface. 
* **Key Features:** Pure text-based UI (no graphics/backslash errors), dynamic life tracking, case-insensitive inputs, and data validation to prevent duplicate guesses.
* **Core Concepts Used:** `while` loops, `set()` for unique letters, validation blocks, conditional `if-else` processing, and `random` word generation.

### 2. Simple Stock Portfolio Tracker
A portfolio management tool that tracks a user's stock investments based on a hardcoded asset pricing dictionary.
* **Key Features:** Live input addition loop, real-time position arithmetic, error fallback for unknown tickers or non-integer amounts, and an **interactive download options menu** allowing users to export reports.
* **Download Formats:** Text summary (`.txt`) and Excel-compatible spreadsheets (`.csv`).
* **Core Concepts Used:** `dict` mapping, custom modular functions, `csv` module integration, input parsing, and advanced file writing (`with open`).

### 3. Rule-Based Chatbot
A smart, interactive CLI chatbot designed to process user prompts and respond with pre-defined answers.
* **Key Features:** Fuzzy keyword matching using the `in` operator to intelligently intercept common user typos like *"hekllow"* or *"how are yoy"*.
* **Core Concepts Used:** Infinite interaction loop (`while True`), string normalization (`.lower()` and `.strip()`), custom function orchestration, and structured logical branches (`if-elif-else`).
